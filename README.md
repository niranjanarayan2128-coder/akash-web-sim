# Akash Web Sim

An open-source, India-inspired flight simulation **prototype**. This early release includes a responsive flight dashboard, a code-generated Three.js scene, a live-position OpenStreetMap minimap, basic simulated controls, and an MCDU-style interface with an optional SimBrief dispatch import.

> **Scope and aircraft accuracy:** the 3D aircraft silhouette and city blocks are procedural placeholders generated by this project. They are **not realistic or to-scale A320 or Boeing 737 models**, and the MCDU is a UI prototype rather than a faithful, fully functional aircraft computer. No sourced aircraft models, cockpit, or airline/aircraft systems are included. The requested realistic B737 and A320 assets remain a prerequisite for a realistic aircraft release.

## Run locally

```sh
npm install
npm run dev
```

Open the Vite URL. Requires Node.js 20 or later.

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds and deploys on pushes to `main`. In **Settings → Pages**, choose **GitHub Actions** as the deployment source. The Vite build uses `/akash-web-sim/` on GitHub Actions and `/` locally.

## Current features and limitations

- Flight state has basic pitch, roll, heading, speed, altitude, throttle and fuel simulation. Keyboard controls: arrows to steer, `W`/`S` for throttle and `Space` to pause/resume. Touch has a simplified flight-control strip.
- The minimap follows the simulated aircraft and heading, expands on request and permits repositioning with a map tap. Map tiles require an internet connection and are served by OpenStreetMap's community tile service. Respect its [tile usage policy](https://operations.osmfoundation.org/policies/tiles/); use a suitable tile provider for substantial traffic. The map is **not satellite imagery**.
- The procedural 3D buildings are illustrative, not sourced city geometry or live building data. They are generated by this project's code; no external 3D models are bundled.
- The MCDU scratchpad accepts a three-digit heading, `FLxxx` target altitude, or 2–5 character fix. It is not connected to an aircraft systems simulation.
- SimBrief import uses its public flight-plan endpoint and requires the pilot's SimBrief user ID. The ID is saved in browser local storage. Import depends on SimBrief and browser/network availability; failures are reported in the interface.
- AIRAC is displayed only when supplied in dispatch data. This project includes **no AIRAC dataset** and does not claim current navigation data, procedures, or operational accuracy. A future adapter must use licensed data and report its source and cycle.
- Weather, audio, aircraft performance, flight dynamics, ATC, airport environment and external camera are not connected to real services.

## Aircraft asset requirements

No third-party aircraft model is presently included because no source with verified permission to redistribute high-quality A320 and Boeing 737 models in this public repository has been established. The prototype silhouette is not offered as a substitute. An aircraft contribution should include the source URL, exact model/version, license text, required attribution, redistribution terms for textures and cockpit parts, and documented cockpit/control mapping. Do not add proprietary paid add-ons, extracted simulator assets, or models whose license is unclear. A license allowing personal use or download does not automatically allow redistribution.
